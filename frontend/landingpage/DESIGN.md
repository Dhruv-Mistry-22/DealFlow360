## Brand & Style

This design system targets high-velocity enterprise sales leaders, CROs, and fintech dealmakers who require instantaneous operational clarity and predictive rigor. The emotional posture is engineered, authoritative, and frictionless—evoking total mastery over complex pipelines and capital allocations. 

The aesthetic fuses **Precision Minimalism** with **Technical Neo-Glassmorphism**:
- Ultra-dense information architecture inspired by developer tools, delivered with the poise of modern institutional finance.
- Layered deep navy canvases that minimize eye fatigue during extended trading and deal-structuring sessions.
- Surgical accents of electric cyan and calibrated semantic signals that guide decision velocity without cognitive noise.
- Sub-pixel borders, hairline data dividers, and dynamic edge illumination that respond seamlessly to user interaction.

## Colors

The palette is engineered specifically for optical performance in dark environments, balancing absolute visual containment with luminous data focal points.

### Background & Surface Hierarchy
- **Canvas Base (`#090D16`)**: Ground-level canvas for outer application architecture and peripheral navigation.
- **Surface Elevation 1 (`#0D1322`)**: Structural grid panels, background data tables, and major structural groupings.
- **Surface Elevation 2 (`#131B2E`)**: Actionable cards, elevated flyouts, metrics clusters, and modals. Must be paired with `rgba(255, 255, 255, 0.08)` hairline borders.
- **Surface Elevation 3 (`#1B253D`)**: Focused elements, dropdowns, contextual action trays, and active rows.

### Functional & Semantic Accents
- **Primary Electric Cyan (`#00F0FF`)**: Core interactivity, key telemetry indicators, active navigational tabs, and focused input states.
- **Secondary Cobalt Blue (`#3B82F6`)**: Secondary brand actions, progress arcs, active link treatments, and synthetic forecasting lines.
- **Healthy Emerald (`#10B981`)**: Closed-won status, positive ARR delta, operational liquidity, and cleared pipeline stages.
- **Pending Amber (`#F59E0B`)**: Deals pending compliance, risk warnings, SLA threshold breaches, and pipeline bottlenecks.
- **Critical Crimson (`#EF4444`)**: Churn signals, deal drop-offs, compliance violations, and anomalous transaction friction.

### Text & Contrast Hierarchy
- **High Emphasis (`#F8FAFC`)**: Primary values, headers, and active pipeline metrics (Alpha 0.98).
- **Medium Emphasis (`#94A3B8`)**: Field labels, secondary metrics, and navigation categories (Alpha 0.70).
- **Muted Subtext (`#475569`)**: Timestamps, disabled interactions, and structural column dividers (Alpha 0.45).

## Typography

The type system balances executive readability with the precision of engineering instruments:

- **Primary Headings (`Plus Jakarta Sans`)**: Applied to all top-level numbers, page titles, and analytical widget headers. The subtle geometric curves add contemporary polish without compromising seriousness.
- **Functional Body (`Inter`)**: Deployed for transactional narratives, form systems, and complex CRM lists. Configured with tabular numbers (`tnum`) across all tabular views.
- **Precision Data (`JetBrains Mono`)**: Reserved for currency denominations, deal values, API status codes, and stage progression timestamps. This prevents layout shifting during real-time data streaming.

## Layout & Spacing

This design system uses an **adaptive 12-column fluid grid** nested inside a docked-shell architecture:

- **Desktop (1280px+)**: Multi-column orchestration with a fixed-width expandable navigational sidebar (`sidebar-expanded`), `1.5rem` (24px) gutters, and outer container padding of `2rem` (32px).
- **Tablet (768px - 1279px)**: Automatic collapse of the primary sidebar to icon mode (`sidebar-collapsed`), layout shifts to an 8-column layout, and secondary data trays transition to full-height drawers.
- **Mobile (Up to 767px)**: Fluid 4-column layout with pinned bottom command bar. Pipeline kanbans convert to paginated swipe views with sticky stage headers.
- **Density Controls**: Data tables support dense (`space-xs` padding) and standard (`space-sm` padding) row heights to accommodate high-volume portfolio scans.

## Elevation & Depth

Spatial layering relies on physical optical boundaries rather than diffuse shadows, preventing mud-like artifacts on OLED and dark displays:

1. **Surface Tint Stacking**: Depth is achieved primarily through progressive brightening of the blue-navy baseline: Canvas (`#090D16`) → Section Container (`#0D1322`) → Card Surface (`#131B2E`).
2. **Glassmorphic Atmosphere**: Active floating elements use background blur (`backdrop-filter: blur(16px)`) with an ultra-sheer fill: `rgba(19, 27, 46, 0.75)`.
3. **Hairline Structural Borders**: Every panel, table container, and card utilizes a 1px inner or outer boundary: `border: 1px solid rgba(255, 255, 255, 0.08)`.
4. **Cyan Luminescence**: Modals, active states, and drag-and-drop landing zones project an electric cyan ambient glow: `box-shadow: 0 0 24px -4px rgba(0, 240, 255, 0.15), inset 0 1px 0 0 rgba(255, 255, 255, 0.12)`.

## Shapes

The system enforces an exacting, mechanical profile:

- **Containers & Data Panels**: Structured at `0.5rem` (8px) for an architectural, dashboard-first look.
- **Inputs, Buttons, & Interactive Controls**: Calibrated at `0.25rem` (4px) to retain sharp tactile feedback reminiscent of physical trading terminals.
- **Status Pills & Micro-Avatars**: Set to full radius (9999px) for immediate visual contrast against rigid rectangular data grids.

## Components

### Buttons
- **Primary**: Background in Electric Cyan (`#00F0FF`) with pure deep navy text (`#090D16`), weight 600. Hover state introduces an outer glow: `box-shadow: 0 0 12px rgba(0, 240, 255, 0.4)`.
- **Secondary**: Elevated dark surface (`#131B2E`) with a crisp border (`rgba(255, 255, 255, 0.1)`) and high-contrast text (`#F8FAFC`). Hover triggers border shift to `rgba(0, 240, 255, 0.5)`.
- **Destructive**: Hairline Crimson border (`#EF4444` at 30%) with crimson-tinted text and transparent background. Active states fill with `rgba(239, 68, 68, 0.15)`.

### Form Inputs & Filters
- Background `#0D1322` wrapped in a 1px border (`rgba(255, 255, 255, 0.08)`). Placeholder text in muted slate (`#475569`).
- Focus state triggers an immediate edge highlight using `#00F0FF` along with a subtle keyline glow: `box-shadow: 0 0 0 1px #00F0FF`.

### Data Cards & Pipeline Kanbans
- Constructed using `#131B2E` at 80% opacity with a `16px` backdrop blur.
- Header bars include an inset highlight (`inset 0 1px 0 rgba(255, 255, 255, 0.06)`).
- Dragged cards elevate to Elevation 3 (`#1B253D`) with a glowing border of `#3B82F6`.

### Status Badges & Chips
- Semantically tinted background at 10% opacity, bordered by the same token at 30% opacity, containing solid text.
- Includes a 6px pulsing dot for real-time telemetry (e.g., active sync, stage changes).

### Checkboxes & Selection Controls
- Base state is an un-filled square with a `rgba(255, 255, 255, 0.2)` border.
- Selected state fills with `#00F0FF`, bearing a dark navy checkmark glyph for high-visibility confirmation.

### Pipeline Health Gauge (Specialized Component)
- Segmented linear or radial track using dark navy base segments (`#131B2E`).
- Real-time score filling via gradient transitions (`#00F0FF` transitioning to `#10B981` based on win-probability calculations).
